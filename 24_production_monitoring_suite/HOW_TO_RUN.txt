PRODUCTION AI MONITORING AND EVALUATION SUITE
=============================================

This module demonstrates post-release monitoring for a parcel-support AI
chatbot.

It covers:

- Operational monitoring
- Safety and policy monitoring
- Intent drift
- Sampled semantic evaluation
- Metric routing
- Human adjudication
- Production-to-regression conversion
- Automated pytest validation


1. PREREQUISITES
----------------

Recommended:

- Python 3.12 or later
- A Python virtual environment
- OPENAI_API_KEY for semantic evaluation
- Internet access for DeepEval evaluator calls

The deterministic monitoring commands do not require an OpenAI API key.


2. ACTIVATE THE VIRTUAL ENVIRONMENT
-----------------------------------

From the repository root:

    source .venv/bin/activate

Move into the module:

    cd 24_production_monitoring_suite


3. INSTALL DEPENDENCIES
-----------------------

    python -m pip install -r requirements.txt

Confirm versions:

    python - <<'PY'

6. VALIDATE THE JSONL EVENT FILES
---------------------------------

    python - <<'PY'
import json
from pathlib import Path

files = [
    Path("data/healthy_production_events.jsonl"),
    Path("data/degraded_production_events.jsonl"),
    Path("data/human_feedback.jsonl"),
]

for file_path in files:
    records = []

    with file_path.open(encoding="utf-8") as file:
        for line_number, line in enumerate(file, start=1):
            try:
                records.append(json.loads(line))
            except json.JSONDecodeError as error:
                raise SystemExit(
                    f"{file_path}:{line_number}: {error}"
                )

    print(f"{file_path}: {len(records)} valid records")
PY

10. METRIC ROUTING
------------------

Grounded parcel-support responses use:

- Answer Relevancy
- Faithfulness

Out-of-scope and unknown intents use:

- Prompt Alignment

Known critical risks use deterministic signals:

- PII incident
- Policy violation
- Unsupported action claim
- Application error


11. APPLY HUMAN REVIEW

16. TROUBLESHOOTING
-------------------

Problem:

    ModuleNotFoundError while running pytest

Check that tests/conftest.py adds the suite root to sys.path before the test
modules are imported.


Problem:

    OPENAI_API_KEY is not configured

Add the key to the repository-level .env file. Do not commit the .env file.


Problem:

    Semantic evaluation scores change between runs

This is expected for LLM-based evaluators. Use thresholds, repeated runs,
human-reviewed labels and deterministic safety checks.


Problem:

    Semantic evaluation error alert

Inspect the error field in the semantic result. Evaluator execution failures
must not be treated as application passes.


Problem:

    Healthy event fails a semantic metric

Review the context, response and evaluator reason. If the automated judgment
conflicts with approved policy, send the event for human adjudication rather
than silently changing the threshold.


17. END-TO-END FLOW
-------------------

    Generate synthetic production events

    Run deterministic monitoring

    Sample high-risk events

    Route events to suitable semantic metrics

    Generate alerts

    Review uncertain evaluator decisions

    Preserve automated and adjudicated reports

    Convert confirmed failures into regression tests

    Execute regression tests before the next release
