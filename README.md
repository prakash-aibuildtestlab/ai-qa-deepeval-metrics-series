# AI QA DeepEval Metrics Series

This repository contains practical examples for learning AI QA testing using DeepEval.

The goal is to explain AI testing step by step, from basic concepts to real evaluation metrics used for LLMs, RAG systems, AI agents, chatbots and safety testing.

## Why this repo?

Traditional QA usually checks fixed outputs.

AI QA is different because LLM outputs can vary, even for the same input. So instead of only checking exact text, we test meaning, behaviour, safety, tool usage and reliability.

## What this series covers

- How AI testing is different from traditional QA
- How to create AI test cases using goldens and datasets
- How to evaluate output quality
- How to test RAG systems
- How to test AI agents and tool usage
- How to test safety risks like bias, toxicity and PII leakage
- How to use DeepEval metrics in a practical QA workflow
